中央氣象署 CWA Open Data API 串接架構說明

本系統採用全螢幕即時氣象視覺化引擎架構，目前以高擬真物理風場與雷達演算法驅動展示。若需接入交通部中央氣象署 (CWA) 氣象資料開放平臺真實即時資料，可依下列端點進行串接：

1. 自動氣象站-氣象觀測資料 (O-A0001-001)
GET https://opendata.cwa.gov.tw/api/v1/rest/datastore/O-A0001-001?Authorization={CWA_API_KEY}

每 10 分鐘更新全台無人與有人測站之即時氣溫 (AirTemperature)、相對濕度、風向風速與日累積雨量。

2. 雷達整合回波圖資料 (O-A0058-003)
GET https://opendata.cwa.gov.tw/fileapi/v1/opendataapi/O-A0058-003?Authorization={CWA_API_KEY}&format=JSON

取得台灣周邊經緯度網格化 dBZ 雷達反射率矩陣，可直接透過 L.imageOverlay 或 WebGL/Canvas 渲染於地圖上方。

3. 天氣警特報與鄉鎮預報 (W-C0033-001 / F-D0047-061)

透過 W-C0033-001 取得豪雨、陸上強風與低溫特報縣市警戒區，並以 F-D0047-061 取得高雄市三民區等鄉鎮逐 3 小時預報資料。
